# UI Design Guidelines

The client has approved the design.

The UI must remain visually identical.

Never redesign.

Never invent new colours.

Never change spacing.

Never change typography.

---

## Theme

Professional.

Minimal.

Financial.

Modern.

Elegant.

Clean.

---

## Components

Rounded corners should remain consistent.

Cards should have identical spacing.

Buttons should follow one design.

Inputs should follow one design.

Icons should remain consistent.

---

## Responsive

Desktop First.

Tablet.

Mobile.

Desktop layout must never break.

---

## Animations

Minimal.

Fast.

Professional.

No excessive animation.

---

## Consistency

Every page should look like it belongs to the same application.
