# Component Guidelines

One responsibility.

Reusable.

Standalone.

Signals.

OnPush.

No API calls.

No duplicated HTML.

No duplicated SCSS.

Prefer Inputs and Outputs.

Use strongly typed models.

Break pages into sections.

Maximum readability.

Document complex logic.

Avoid unnecessary lifecycle hooks.

Use inject().

Prefer computed().

Prefer signal().

Avoid deeply nested templates.
