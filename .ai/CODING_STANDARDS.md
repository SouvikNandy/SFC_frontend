# Coding Standards

## TypeScript

Strict typing.

No any.

Use interfaces.

Use readonly.

Prefer const.

Never disable lint rules.

---

## Angular

Standalone Components.

Signals.

inject().

OnPush.

Lazy Loading.

Strong typing.

---

## HTML

Semantic.

Accessible.

Reusable.

Simple.

---

## SCSS

Variables.

Mixins.

Reusable utility classes.

No inline styling.

---

## Components

Single Responsibility Principle.

Maximum readability.

Reusable.

Small methods.

Avoid duplicate code.

---

## Services

Components never call HttpClient.

Only services access APIs.

---

## Methods

Small.

Self descriptive.

One responsibility.

---
